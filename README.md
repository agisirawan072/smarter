## 📖 Tentang SMARTER

**SMARTER** adalah aplikasi web edukatif modern yang dirancang khusus untuk anak-anak usia **6 hingga 10 tahun (Tingkat SD)**. Menggabungkan kurikulum dasar **Matematika** dan **Bahasa Inggris** dengan pendekatan permainan (*gamification* ala Duolingo & Brawl Stars), SMARTER mengubah proses belajar yang tadinya membosankan menjadi petualangan interaktif penuh bintang, animasi, suara penutur asli (*native speaker*), dan hadiah seru.

---

## ✨ Fitur-Fitur Unggulan

### 1. 🧮 Pojok Materi Matematika (12 Modul Bergambar Lengkap)
Materi konsep hitung dasar hingga logika disajikan secara bertahap dengan visual ramah anak:
- **Penjumlahan Ceria (6–7 Thn)** — Trik berhitung maju dan pasangan teman sepuluh.
- **Mengenal Bangun Datar 2D (6–8 Thn)** — Segitiga, persegi, persegi panjang, dan lingkaran di sekitar rumah.
- **Pengurangan & Logika (6–8 Thn)** — Trik hitung mundur dan soal cerita balon meletus.
- **Rahasia Perkalian Mudah (7–9 Thn)** — Penjumlahan berulang, perkalian 2, perkalian 5, dan sifat angka 0 & 1.
- **Menebak Pola & Barisan (6–9 Thn)** — Pola bilangan loncat (+2, +3) dan urutan warna.
- **Pengukuran Panjang & Jam (7–10 Thn)** — Satuan cm vs meter serta membaca jarum jam analog.
- **Pembagian Ceria & Bagi Rata (8–9 Thn)** — Berbagi permen adil dan kebalikan dari perkalian.
- **Pecahan Seru ½, ⅓, ¼ (7–8 Thn)** — Konsep pembilang-penyebut lewat potongan pizza.
- **Mengenal Uang & Belanja Pintar (7–10 Thn)** — Koin dan uang kertas rupiah serta hitung uang kembalian.
- **Menjelajah Bangun Ruang 3D (8–10 Thn)** — Kubus, balok kardus, tabung kaleng, kerucut, dan bola.
- **Diagram Gambar & Piktogram (8–10 Thn)** — Membaca simbol buah dan diagram batang.
- **Trik Sulap Berhitung Cepat (Semua Usia)** — Tambah 9 kilat, jari perkalian 9, dan bilangan ganjil-genap.

### 2. 🇬🇧 Kids English Explorer (12 Modul Audio Native Speaker)
Kurikulum dasar bahasa Inggris anak dengan pelafalan kata asli:
- **The Alphabet & Phonics Song** — Fonik bunyi huruf dan vokal ajaib (A, E, I, O, U).
- **First Sight Words & Kalimat Pertama** — Membaca kata penglihatan harian (*I, see, can, like*).
- **Counting Numbers 1 to 20** — Belajar angka dan berhitung benda dalam bahasa Inggris.
- **Rainbow Colors & Magic Paints** — Mengenal warna-warni pelangi dan alam.
- **Zoo & Farm Animals** — Hewan peliharaan dan satwa kebun binatang.
- **Delicious Fruits & Healthy Food** — Buah-buahan segar dan sarapan sehat.
- **My School Bag & Classroom** — Benda-benda di dalam tas sekolah dan kelas.
- **My Beloved Family** — Silsilah keluarga tercinta (*Father, Mother, Brother, Sister*).
- **Daily Greetings & Polite Manners** — Sapaan harian dan kata ajaib sopan santun (*Please, Thank You*).
- **Shapes Around Us** — Bentuk geometri dalam bahasa Inggris.
- **Math in English (Plus & Minus)** — Melafalkan operasi hitung matematika dalam bahasa Inggris.
- **My Body & Action Verbs** — Anggota tubuh dan kata kerja aksi ceria (*Clap, Jump, Run*).

---

### 3. 🎮 Laboratorium & Studio Interaktif
- **🔢 Tabel Perkalian 1–10 (Hingga 100):** Pemilih angka dinamis yang menampilkan perkalian 1 s/d 10.
- **📊 Matriks Pythagoras 10×10:** Modal tabel kotak 100 interaktif dengan efek sorot silang baris × kolom dan piala 100.
- **🍕 Simulator Pecahan Pizza SVG:** Memotong pizza secara dinamis (1/2, 1/3, 1/4, 1/6, 1/8) untuk memvisualisasikan pecahan.
- **🪙 Kasir Cilik (Hitung Uang Rupiah):** Praktik menabung dan belanja dengan koin Rp500, Rp1.000, uang Rp2.000, dan Rp5.000.
- **🔊 English Soundboard:** Kartu suara audio pelafalan kata asli (*native English*) dengan Web Speech Synthesis.
- **💬 Mini Dialogue Studio:** Latihan percakapan kalimat utuh berbahasa Inggris.

---

### 4. 🗺️ Silabus Kursus Berjenjang
Navigasi peta belajar (*curriculum roadmap*) untuk Matematika dan Bahasa Inggris dari Tingkat Pemula (*Level 1*), Menengah (*Level 2*), hingga Mahir (*Level 3*). Setiap pencapaian (*milestone*) terhubung langsung ke modul materi yang bersangkutan.

---

### 5. 🎯 Bank Soal Kuis Interaktif
- Menyediakan **28+ soal latihan interaktif** dengan kategori terstruktur.
- Dilengkapi fitur bantuan bohlam (*hint*) dan penjelasan konsep yang ramah anak.
- Mengumpulkan **+10 Bintang** untuk setiap jawaban yang benar.

---

### 6. ⚡ Game Kilat "Hitung Cepat 30 Detik"
- Mini game adu ketangkasan berhitung dengan batas waktu mundur 30 detik.
- Sistem kombo beruntun (*Streak Multiplier*) untuk melipatgandakan perolehan bintang.

---

### 7. 🎡 Roda Hadiah Berputar (Carnival Spin Wheel)
- Roda keberuntungan karnaval 8 sektor dengan animasi fisika putaran realistis dan deselerasi halus.
- Lampu LED sirkus berkedip dan efek suara klik mekanis.
- Menangkan hadiah hingga **+50 Bintang** dan **Mahkota Emas Juara**.

---

### 8. 🏅 Lemari Lencana Prestasi (12 Badges)
Anak dapat membuka 12 lencana prestasi khusus seiring perjalanan belajar (contoh: *Master Penjumlahan, Raja Geometri, Bintang Kuis, Rekor 30 Detik, Rajin 7 Hari*, dll).

---

### 9. 👨‍👩‍👧 Portal Pantauan Orang Tua (*Parent Dashboard*)
- Statistik waktu belajar dan rasio akurasi kuis.
- Grafik radar perkembangan kompetensi anak.
- Rekomendasi pendampingan belajar di rumah.

---

### 10. 🤖 Teman Robot Maskot "Koko"
Maskot melayang interaktif yang siap menyapa, memberikan semangat, tips hitung cepat, dan obrolan ramah anak kapan saja.

## 📱 Desain Responsif & Antarmuka Ceria

- **Duolingo-Style 3D Tactile Buttons:** Tombol bertekstur empuk dengan efek kedalaman 3D dan animasi pantulan lembut.
- **Glassmorphic Floating Navbar:** Bar navigasi melayang modern dengan *backdrop blur*, indikator tab aktif warna biru kontras, dan status bintang/streak api.
- **Mobile Bottom Navigation Bar:** Navigasi 5 tombol jempol di bagian bawah layar ponsel (`Beranda`, `Silabus`, `Materi`, `Kuis`, `Menu Drawer`).
- **Optimal di Semua Perangkat:** Tampilan proporsional di layar Desktop (1920×1080, 1366×768), Tablet / iPad, hingga Ponsel pintar Android & iPhone.

## 🛠️ Teknologi yang Digunakan

| Komponen | Teknologi | Deskripsi |
|---|---|---|
| **Frontend Framework** | React 18 (Hooks, State) | Antarmuka pengguna komponen modular & reaktif |
| **Build Tool & Bundler**| Vite 5 | Server pengembang super cepat & hot-reload instan |
| **Styling** | Vanilla CSS3 (Custom Properties) | Desain 3D, Glassmorphism, CSS Grid & Flexbox |
| **Audio & Speech** | Web Speech API | Pelafalan suara bahasa Inggris (*Native Speaker*) |
| **Backend API** | Node.js & Express.js | REST API penyimpan skor bintang dan aktivitas |
| **Komunikasi Data** | RESTful JSON & CORS | Integrasi data Frontend ke Backend |

## 🚀 Panduan Menjalankan Proyek Secara Lokal

Pastikan Anda telah menginstal **[Node.js](https://nodejs.org/)** (versi 16 atau lebih baru) di komputer Anda.

### 1. Klon Repositori
```bash
git clone https://github.com/indoc/smarter.git
cd smarter
```

---

### 2. Jalankan Server Backend
Buka terminal baru di folder `backend`:
```bash
cd backend
npm install
npm start
```
Server Backend akan berjalan di **`http://localhost:5000`**.

---

### 3. Jalankan Server Frontend
Buka terminal baru lainnya di folder `frontend`:
```bash
cd frontend
npm install
npm run dev
```
Server Frontend Vite akan berjalan di **`http://localhost:5173`**.

---

### 4. Buka di Browser
Buka browser favorit Anda (Google Chrome / Microsoft Edge) dan kunjungi:
👉 **[http://localhost:5173](http://localhost:5173)**

## 📡 Daftar Endpoint Backend API

| Metode | Endpoint | Deskripsi |
|---|---|---|
| `GET` | `/api/smarter-data` | Mengambil data total bintang dan daftar kartu aktivitas |
